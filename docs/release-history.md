- CLI/MCP 目录、桌面 v5 识别、状态解释和三份 Skill 同步更新。具体范围见[审批策略](approval-policy.md)。

## 0.8.6 通用读取审批与命令选择验证

### 行为

- 任意字面相对/绝对文件路径均可匹配，包括中文、空格和 `..`；不按日志目录或后缀限制。完整参数、引号和每个管道段均检查，原始命令不改写。
- 支持 cat、grep、head、tail 的列明参数，以及显式禁用分页、有限行数的 journalctl。独立无文件输入、持续跟随、变量/命令替换、未引用通配符、重定向、任意解释器和混入写操作的命令不匹配。完整范围见 [审批规则](approval-policy.md)。这不是远端路径或可执行文件沙箱。
- 当前目标身份、代次和心跳仍须有效；停用状态持久保存。旧 pending 不补批，unknown 不重放，旧包队列任务不凭新包自动派发。CLI、MCP、桌面继续共享服务端仲裁。
- Skills 按末尾、开头、字面匹配、正则、最后匹配、完整计数、时间范围和全文需求选择命令。明确 grep -m 是从开头遇到的匹配数，完整计数不加 -m；退出 1 与读取错误分开，管道末段成功不证明前段成功。复杂引号优先 UTF-8 command-file；已提交任务不改写规避审批。
